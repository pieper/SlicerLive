Whole-brain tractography — capsule tubes WebGPU

The fiber bundles of a live 3D Slicer scene (SlicerDMRI, clustered into 42 named tracts by TractCloud), streamed into SlicerLive and drawn as piecewise-linear capsule tubes inside the ray-march — the same rendering as the synthetic fiber demo, on real data. A deterministic 10% of each bundle's streamlines loads by default, which is a contiguous prefix of each file, so it is a small range request rather than the full 22 MB (add ?fraction=0.5 to load more). The SlicerLive badge mirrors the Slicer Data module's grouping: one opacity control per tract group — Association, Cerebellar, Commissural, Projection, Superficial.  ·  SlicerLive
