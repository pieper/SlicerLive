Remote RenderDeno · WebGPU · WS

The same TS/WebGPU renderer, running headless in a Deno process, streaming traced samples over a WebSocket. This page just sends its camera and reconstructs the samples (Catmull-Rom upsample + background composite) — the identical Reconstructor the local demos use. Drag to orbit. Toggle the same scene between your local GPU and the remote renderer. Start the server with deno run --unstable-webgpu --allow-net --allow-read --allow-env server/live-renderer.ts.
